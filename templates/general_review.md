复盘不是流水账，也不只做机械挑刺。请结合本次录音转录稿（特别留意 `> [语气]` 情绪波动与 `> [叠话]` 现场细节）以及上方提供的「用户背景说明」，**先定性场景级别，再动态激活最值钱的分析镜头**，写出一份精炼、直接、保留关键事实锚点的中文深度复盘文档。

## 第一步：四类场景自动路由（先定级，再按级展开）
1. **S 级 · 客户谈单 / 售前调研 / 商务谈判 / 核心汇报**
   - 重点看话术与潜台词、经营/商业账本（是否陷入纯技术或执行细节？有没有问清对方真实痛点、决策链、成本损失与 ROI？能否抽成可复用杠杆？）与下一步推进动作。
2. **A 级 · 内部讨论 / 方案评审 / 复盘分享 / 个人深度思考**
   - 重点提炼对方真正想点醒的深层意图或自身盲区，警惕工具自嗨/偏离主线，拉回目标、投入产出比与质量验收标准，给出最小验证动作。
3. **A-人情级 · 熟人 / 长辈 / 合作方茶局饭局**
   - 重点抓出哪些话接得太直、太干、扫兴或丢掉主导权，给出自然、不卑不亢、有温度的高情商接话示范（绝不硬套工作 KPI），并顺手留档商业/行业见闻与重要私人备忘。
4. **C 级 · 短测试 / 误触 / 无有效对话**
   - 极简 3 行概括归档，直说「无明显卡点」，绝不硬挑刺；跳过「30 秒速览快报」与「动态深度视角」。

## 第二步：输出结构要求
请以 YAML Frontmatter 开头（包含 `类型: 语音复盘`、`时间`、`标题`、`时长`、`级别: S|A|A-人情|C`、`模板: 深度多镜头实战复盘`、`说话人`），随后按以下结构组织正文：

### 30 秒速览快报（仅 S / A / A-人情级输出，严格 ≤300 字）
- **📌 核心局势**：1～2 句说清跟谁聊、聊了什么结果；
- **⚡ 关键视角提醒**：1 句直戳最关键盲区、业务杠杆或节奏问题；
- **💬 改口 / 补救建议**：1 句自然口语替代话术或行动要点（无明显卡点可省）；
- **👉 下一步**：1 条最高价值可执行动作。

### 一、核心摘要与关键事实
- 用 3～5 句交代跟谁聊、沟通背景、核心议题以及达成的结论或卡点；
- **强制留住事实锚点**：完整保留原文中出现的人物/行业、具体数字、报价/预算、时间节点、明确承诺与关键约束条件，确保日后回溯不丢干货。

### 二、没接稳 / 接不上的地方 & 下次怎么说得更好
- 只列有原文 `[HH:MM:SS]` 依据的真实卡点（C 级或整场顺畅则如实说明「无明显卡点」）；
- 每条按顺序写清：
  1. `[HH:MM:SS]` 原话摘录（≤ 2 句）；
  2. 结合 `> [语气]` / `> [叠话]` 标注判断现场情绪、气场变化与对方没说出口的真实顾虑；
  3. 哪里没接稳（如接得太直、漏了信号、陷入细节自说自话）；
  4. **自然口语替代话术**：给出 1～2 句可直接说出口的更好表达。

### 三、动态深度视角（按场景自动激活 1～3 项，C 级可略）
- **经营 / 决策视角体检**（S / A 级）：是否停留在执行/技术细节？关键商业账本、ROI 与决策链是否摸清？有没有更高杠杆的做法？
- **目标主线与自我盲区纠偏**（A 级）：是否偏离用户当前最核心的目标或陷入局部优化？给出最小可验证动作；
- **人情节奏、见闻与人物备忘**（A-人情级 / 含重要新人物时）：提炼可留档的行业见闻、对方最在意的事或重要日程备忘；
- **下一步最高价值动作 & 值得补齐的信息**：给出 1～3 条高价值动作，注明哪些是「已明确承诺」、哪些是「AI 建议待确认」。

## 硬性纪律（六层严谨口径）
- **先认准「我」**：已通过本地声纹标出本人姓名时直呼其名；未自动认出时结合上下文推断并注明「待确认」。
- **只说有原文依据的话**：严禁脑补未出现的数字、人名、预算或承诺；每个卡点必须带 `[HH:MM:SS]` 锚点。
- **严格区分六层口径**：清晰区分**原话、事实、感受、假设/解释、建议、结果**——绝不把 AI 建议擅自写成用户的承诺待办。
- **直给、克制、不废话**：不写空泛客套与安慰，不把单次表现上升为人格评价；宽容明显的转写错别字和口语停顿。
